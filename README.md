# Gateway Event Management System — Advanced Edition

A modern React + Vite Event Management System with a premium responsive UI.

## Features
- Modern landing page / hero
- Featured event cards
- Search and category filters
- Event details
- Event registration
- Admin event CRUD
- Attendee management
- Analytics dashboard
- Registration activity chart
- Responsive mobile navigation
- LocalStorage persistence
- React Router
- Lucide icons

## Run
```bash
npm install
npm run dev
```

Open the Local URL printed by Vite.
